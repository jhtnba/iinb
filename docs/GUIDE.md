# IINB 使用指南

## 1. 在“设置 → 用户界面 → 播放控制条”选择“底部”。

在“设置 → 用户界面 → 播放控制条”选择“底部”。

## 2. 打开一个视频

打开一个视频，将其他视频加入播放列表；双击列表项播放，单击只选中。

## 3. 通过列表排序菜单选择时长、大小或标签；有无标签分组与标签文字无关。

通过列表排序菜单选择时长、大小或标签；有无标签分组与标签文字无关。

## 4. 首次加载新文件的时长仍需读取磁盘

首次加载新文件的时长仍需读取磁盘，后续使用缓存；机械硬盘扫描需要等待。

## 5. 安装发布附件中的审阅标记插件

安装发布附件中的审阅标记插件，启用后重新启动。

## 6. 在控制条自定义中加入“标记已审阅”和删除按钮；删除可选择音量左侧或右侧工具区。

在控制条自定义中加入“标记已审阅”和删除按钮；删除可选择音量左侧或右侧工具区。

## 7. 审阅插件开启“只看未审阅”后

审阅插件开启“只看未审阅”后，会跳过已有“已审阅”标签的文件。需要按列表完整播放时先关闭此项。

## 操作边界

- 基于 IINA 1.5.0 修改，不是 IINA 官方发布或官方支持版本。
- 审阅按钮需要配套插件；单独安装 App 不等于插件已启用。
- 关闭窗口和退出不会自动计入审阅；切换视频和手动完成仍按插件规则计数。
- 删除按钮将文件移到废纸篓；删除最后一项停止，不回到上一项。
- 不通过官方更新覆盖定制版，升级需下载新的定制构建。
