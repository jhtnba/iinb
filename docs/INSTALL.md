# 安装与升级

1. 从本项目 Releases 下载对应 DMG，确认版本和系统要求。
2. 双击打开 DMG，将 App 拖到 Applications（应用程序）快捷入口。
3. 弹出磁盘映像，从“应用程序”打开软件。
4. 升级前退出旧版，建议先备份旧 App；再替换应用。

个人构建目前没有开发者 ID 公证保证。遇到系统拦截时先核对下载来源和校验值，只在信任文件时使用 macOS 提供的打开方式；不需要关闭系统整体安全保护。

不支持 Intel 的发布包不能在 Intel Mac 使用。最低系统版本以当前下载包说明为准。

## 当前要求

本发布包要求 macOS 12 或更新版本；Apple Silicon。
