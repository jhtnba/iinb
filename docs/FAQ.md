# 常见问题

## 为什么打不开？

确认 macOS 版本、处理器架构和下载包要求一致。若系统提示无法验证开发者，请核对官方项目链接与校验值。当前个人构建不宣称经过 Apple 公证。

## 怎样升级？

退出旧版，从本仓库 Releases 下载新 DMG，备份旧 App 后替换。不要把软件本体的替换当成用户数据备份。

## 可以提交功能建议吗？

可以，请在 Issues 中说明使用场景。建议不等于已经实现或承诺交付。

## 发现问题怎么办？

提交应用版本、系统版本、完整复现步骤和去除私人信息的截图。请勿上传私人媒体或个人文件列表。

## 已知限制

- 基于 IINA 1.5.0 修改，不是 IINA 官方发布或官方支持版本。
- 审阅按钮需要配套插件；单独安装 App 不等于插件已启用。
- 关闭窗口和退出不会自动计入审阅；切换视频和手动完成仍按插件规则计数。
- 删除按钮将文件移到废纸篓；删除最后一项停止，不回到上一项。
- 不通过官方更新覆盖定制版，升级需下载新的定制构建。
- 保留原作者版权及 GPLv3 许可证；公开分发需提供对应源码获取方式。
